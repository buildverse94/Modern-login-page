# 💜 Modern Login Page with 3D UI

A sleek, stylish, and fully responsive **Modern Login Page** created using **HTML5, CSS3, and Vanilla JavaScript**. It features an eye-catching split-screen layout with an animated 3D character illustration card, clean form inputs, and custom social login integration.

---

## ✨ Key Features

* 📱 **Responsive Design:** Optimized for seamless performance on desktop, tablet, and mobile screens.
* 🎨 **Modern & Clean UI:** Aesthetic dark/light contrast theme with smooth purple gradient accents.
* 🔒 **Interactive Form Components:** Clean input fields for Email & Password, "Remember Me" checkbox, and "Forgot Password?" option.
* 🌐 **Social Authentication:** Integrated "Continue with Google" action button.
* ⚡ **Beginner Friendly & Simple Code:** Clean, modular structure using pure HTML, CSS, and JS.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styling, Flexbox/Grid layout, and smooth UI transitions.
* **JavaScript (ES6):** Client-side interactivity and logic.
